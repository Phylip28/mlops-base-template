## Visual Contract — API Section Layout Fix

### Problem
API section content is too wide and breaks visual identity compared to Services and Infrastructure sections. The API card does not match the service card styling.

### Current State
- API page uses inline card HTML with custom structure
- Card width is not constrained to match service cards
- Visual inconsistency with other sections

### Fix Specification

**File:** `streamlit_app/pages/api.py`

**Change 1:** Constrain API card width to match service card dimensions

Add a column wrapper to constrain the card width:

```python
# Current:
st.markdown(f"""<div class="card card-striped {"green" if api_up else "red"}">...""")

# Fixed: Wrap in column with constrained width
api_cols = st.columns(3)
with api_cols[0]:
    st.markdown(f"""<div class="card card-striped {"green" if api_up else "red"}">...""")
```

**Change 2:** Update status text to English

```python
# Current:
{"Activo" if api_up else "Inactivo"}

# Fixed:
{"Online" if api_up else "Offline"}
```

### Card Width Constraint

| Property | Value |
|----------|-------|
| Max-width | Match service card (implicit via 3-column grid, first column) |
| Alignment | Left-aligned in first column of 3 |
| Min-height | Inherit from `.card` class (no explicit min-height needed) |
