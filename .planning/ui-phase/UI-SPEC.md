## Visual Contract — Grafana Grid Fix

### Problem
Grafana card is incorrectly positioned at `grid-column: 2; grid-row: 2` instead of `grid-column: 3; grid-row: 2`.

### Expected 2-Row Infrastructure Grid Layout

```
Row 1: [PostgreSQL(col1)] [MinIO(col2)]     [MLflow(col3)]
Row 2: [Prometheus(col1)] [empty(col2)]     [Grafana(col3)]
```

Services list (from utils.py):
0. PostgreSQL → col:1, row:1 ✓
1. MinIO → col:2, row:1 ✓
2. MLflow → col:3, row:1 ✓
3. Prometheus → col:1, row:2 ✓
4. Grafana → col:3, row:2 (currently col:2, row:2 — WRONG)

### Fix Specification

**File:** `streamlit_app/sections/services.py`
**Function:** `_card_html()`

**Change:** Add conditional override for Grafana to set `grid-column: 3; grid-row: 2`

```python
# Current (WRONG for Grafana at idx=4):
col = idx % 3 + 1
row = idx // 3 + 1
# → col=2, row=2 for Grafana (idx=4)

# Fixed:
col = idx % 3 + 1
row = idx // 3 + 1
if name == "Grafana":
    col = 3
    row = 2
# → col=3, row=2 for Grafana
```

### Card CSS (pre-existing, no changes needed)

| Property | Value |
|----------|-------|
| Grid container | `.svc-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; }` |
| Card min-height | `.svc-card { min-height: 180px; }` |
| Card padding | `.svc-card { padding: 18px 16px; }` |

### Focal Points
- Grafana card must align right edge with MLflow card (col 3)
- Grafana card must align horizontally with Prometheus (same row 2 baseline)
- Col 2, row 2 remains empty (no phantom card)
