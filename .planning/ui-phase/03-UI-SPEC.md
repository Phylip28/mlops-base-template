## Visual Contract — Navigation Flash Fix

### Problem

When navigating between sections, a white flash appears before the next page loads. This breaks immersion and violates the dark theme consistency.

### Root Cause

Streamlit's default page background is white. The custom CSS (`styles.py`) sets `background: var(--bg-body)` on `.stApp`, but this applies after the page renders. During navigation, the white default shows through.

### Fix Specification

**File:** `run_streamlit_app.py`

**Change:** Add CSS to hide the page content during navigation transition, revealing only after the custom background is applied.

Add this CSS block to the `<style>` injection in `run_streamlit_app.py`, immediately after `st.markdown(CSS, unsafe_allow_html=True)`:

```css
/* Navigation flash fix — hide content until custom styles load */
.stApp {
    visibility: hidden;
    opacity: 0;
    transition: opacity 0.15s ease, visibility 0.15s ease;
}
.stApp[data-testid="stApp"]:has(> div[data-testid="stMain"]) {
    visibility: visible;
    opacity: 1;
}
```

**Alternative approach (more reliable):** Inject a small CSS snippet that overrides the default background at the document level:

```python
st.markdown(
    """
    <style>
    /* Override Streamlit default white background at document level */
    .stApp > div[data-testid="stMain"] {
        background-color: var(--bg-body) !important;
    }
    /* Smooth fade-in for page transitions */
    div[data-testid="stMain"] {
        animation: fadeIn 0.12s ease-in;
    }
    @keyframes fadeIn {
        from { opacity: 0; }
        to { opacity: 1; }
    }
    </style>
    """,
    unsafe_allow_html=True,
)
```

**Recommended:** Add to `styles.py` CSS variable definitions:

```css
/* Add to :root block in styles.py */
--page-transition-bg: #0f141a;
```

Then add this CSS immediately after the main CSS injection in `run_streamlit_app.py`:

```python
st.markdown(
    """
    <style>
    /* Navigation flash prevention — override default white background */
    div[data-testid="stMain"] {
        background-color: #0f141a !important;
    }
    /* Smooth fade transition for page content */
    section.main > div {
        animation: pageFadeIn 0.1s ease-out;
    }
    @keyframes pageFadeIn {
        from { opacity: 0; transform: translateY(4px); }
        to { opacity: 1; transform: translateY(0); }
    }
    </style>
    """,
    unsafe_allow_html=True,
)
```

### Visual Behavior

| State | Behavior |
|-------|----------|
| Initial load | Dark background (#0f141a) visible immediately |
| Navigation | Content fades in with 0.1s animation, no white flash |
| Transition | Smooth opacity + 4px vertical slide |

## Visual Contract — API Section Button Redesign

### Problem

Buttons in the API section are too large for the small card container (360px max-width). The current button height (40px) and padding create visual imbalance.

### Current State

```python
# api.py line 39-71
c1, c2 = st.columns(2)
with c1:
    st.button("▶  Start API", key="api_start", use_container_width=True, type="primary")
with c2:
    st.button("■  Stop API", key="api_stop", use_container_width=True, type="secondary")
```

**Issue:** Buttons span full column width (~180px each) but height (40px) feels bulky relative to the compact card.

### Redesign Specification

**File:** `streamlit_app/pages/api.py`

**Change 1:** Reduce button height via inline style override

Add custom CSS class for compact buttons:

```python
# Add at top of render() function
st.markdown(
    """
    <style>
    .api-button-row .stButton > button {
        height: 36px !important;
        padding: 8px 16px !important;
        font-size: 11px !important;
        font-weight: 700 !important;
        letter-spacing: 0.3px !important;
    }
    </style>
    """,
    unsafe_allow_html=True,
)
```

**Change 2:** Apply class to button container

```python
# Current:
c1, c2 = st.columns(2)

# Fixed: Wrap in styled container
st.markdown('<div class="api-button-row">', unsafe_allow_html=True)
c1, c2 = st.columns(2)
# ... buttons ...
st.markdown('</div>', unsafe_allow_html=True)
```

**Change 3:** Update button labels for better proportions

```python
# Current:
"▶  Start API"
"■  Stop API"

# Fixed (tighter spacing, all caps for consistency):
"▶ Start"
"■ Stop"
```
